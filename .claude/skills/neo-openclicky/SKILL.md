Begin with read-only inventory, then expand to a reversible project edit/build only after independent verification. Never switch to paid inference silently.

Pause immediately before the concrete consequential action when approval is absent. Do not request manual copy/paste relays. After execution inspect files, source, git diff, tests/build and application state independently. Repair within the `neo-loops` budget and update persistent state.
